# Internal pre-submission checklist

- [x] Natural-language request and optional starting URL API/UI.
- [x] Actual LangGraph workflow, bounded attempts/pages/hops/deadline.
- [x] TinyFish adapter implemented from official API reference.
- [ ] TinyFish Search/Fetch/Agent validated with real credentials.
- [x] Real static HTTP retrieval validated.
- [ ] Real Playwright fallback validated; Chromium installation outstanding.
- [x] Configurable LLM adapters and free-only provider policy.
- [ ] At least one real LLM provider returns a valid grounded answer.
- [x] Genuine passage citations, rejection of invalid quotes and unsupported extracts in fixtures.
- [x] Abstention, scoped navigation, contradiction/freshness heuristics.
- [x] Local automated suite and machine-readable fixture benchmark.
- [ ] Held-out live benchmark and semantic evidence review.
- [x] Deployment configuration and documentation.
- [x] Docker image built/tested locally; [ ] target AMD execution validated.
- [ ] Official starter kit acquired, actual AMD adapter implemented.
- [ ] Confirm allowed network, models, external API use, deadlines and submission materials.
- [ ] Final demonstration and submission review.
- [ ] User approval before any publishing or deployment.
